Don't just chat with AI. Put it to work.

Kbot is a desktop app for personal AI agents. Make a bot for a job, and it chats with you, runs every morning, follows a schedule, or works with other bots as a team. It runs on Claude or Codex, and your bots and chats are stored on your computer.

See it work

Five things Kbot does

Each clip is a real run through the app, from an empty sidebar to a finished answer.

1

Create a bot and chat with it

Name a bot, pick a picture, and choose "Chat with me". The bot sets itself up in the chat by asking you a few questions.

  • Turn web access on or off
  • Pick the folder it works in
  • Tell it what to focus on, then just ask
2

A bot that runs every day

Choose "Run a daily job", set the time and the days, and the bot does its work on its own. Results land in the chat with an unread count and a Dock badge.

  • Pick the time and the weekdays
  • Change the job later in Settings
  • Hit "Run now" to try it right away
3

Schedule a task

Choose "Schedule a task" for work that runs on a date, every few hours, or every month, like a monthly expense report.

  • Run once, at an interval, or monthly
  • Point it at a folder of files
  • Run it early from the chat header
4

Agent Teams

Put bots together in a team and give it a goal. A lead plans the work, hands each part to the right member, and brings the results back as one answer.

  • Add existing bots or create new ones
  • Let the team decide, or set a custom flow
  • Open any member's chat to see its work
5

Pick the AI for each bot

Every bot can use its own provider, model and reasoning effort. Put a hard research job on a big model and a quick sorter on a fast one.

  • Claude or Codex, per bot
  • Model and effort in Edit › AI Provider
  • "Use Kbot Settings" to follow the app default
Everything in Kbot

Features

All of it, from every release so far.

Personal agents

Make a bot for each job. Each one has its own name, picture, instructions, folder and chat history.

1.0.0

Setup in the chat

A new bot asks what it should do, then writes its own instructions for you to confirm.

1.0.0

Edit any time

Type /setup and say what to change in your own words, even "rename yourself". Or right-click a bot and choose Edit to change its name, instructions, folders and web search in one place.

1.0.1

Scheduled jobs

Run a bot daily on chosen weekdays, every few minutes or hours, on a set date, or once a month. Kbot runs the job and posts the result.

1.0.0

Unread counts and Dock badge

When a job finishes while you're away, the bot shows an unread count in the sidebar and the Dock icon shows the total.

1.0.0

Questions and approvals

When the AI needs a choice or your OK before it acts, the options show up in the chat as buttons.

1.0.0

Your data stays local

Bots and chats are stored in SQLite on your computer. Kbot runs the Claude Code or Codex CLI you're already signed in to.

1.0.0

Bot pictures and a resizable sidebar

Pick one of 20 bot pictures so you can tell your bots apart. Drag the sidebar to the width you like, and double-click its edge to reset it.

1.0.1

Claude or Codex, plus dark mode

Run on Claude Code or the OpenAI Codex CLI, including a local model through Codex. Pick the model and reasoning effort in Settings › AI Providers. Dark mode covers the whole app.

1.0.2

Tags, filters and search

Group bots with colored tags. Click a tag chip to filter the sidebar, or search by bot or tag name.

1.0.3

Chat commands

Type / in the chat box: /setup to change the bot, /clear-history to clear the chat, /delete to remove the bot.

1.0.3

Agent Teams

Send one message to a team. The lead plans the work, hands out tasks, checks each result and replies with one answer. Let it decide, or drag members into a custom flow. Pause, retry or skip from the plan card, and @mention one member.

1.0.4

MCP servers and tools

Bots run isolated by default. Turn on the switch and a bot uses your own CLI setup: MCP servers like JIRA, plugins, hooks, and Claude in Chrome.

1.0.4

An AI model for each bot

Give any bot its own provider, model and effort in Edit › AI Provider. Chats, jobs and teams all use it, and changing it keeps the conversation.

1.0.5

Get started

Install Kbot

Three steps on a Mac or a Windows PC.

1Download and install

macOS
  1. Download Kbot_1.0.5_universal.dmg.
  2. Open it and drag Kbot into Applications.
Windows
  1. Download Kbot_1.0.5_x64-setup.exe.
  2. Run it and follow the steps. Kbot is added to the Start menu.

2Allow it the first time

macOS
  1. The build isn't notarized by Apple yet, so macOS blocks the first launch. Open System Settings › Privacy & Security, scroll down and click Open Anyway.
  2. Or run this in Terminal:
xattr -dr com.apple.quarantine /Applications/Kbot.app
Windows
  1. The installer isn't code-signed yet, so Windows may say "Windows protected your PC". Click More info, then Run anyway.

3Sign in to an AI

Claude (the default) needs a Pro or Max plan. Codex works with ChatGPT sign-in, an API key, or a model set in ~/.codex/config.toml.

macOS
# Claude
curl -fsSL https://claude.ai/install.sh | bash
claude auth login

# or Codex
npm install -g @openai/codex
codex login
Windows (PowerShell)
irm https://claude.ai/install.ps1 | iex
claude auth login

Claude Code on Windows also needs Git for Windows. On Windows, use Claude for now. Codex support there is still in progress.
